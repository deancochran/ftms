# Security Policy

## Supported versions

Until `1.0.0`, only the latest published `0.x` version receives security fixes.

## Reporting a vulnerability

Use GitHub private vulnerability reporting for
[`deancochran/ftms`](https://github.com/deancochran/ftms/security/advisories/new).
Do not disclose suspected vulnerabilities, device identifiers, private captures,
credentials, or personal data in a public issue.

Include the affected version, expected and actual behavior, impact, and a
minimal redacted reproduction when possible.
